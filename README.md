# 2D Crystallographic Symmetry Workbench

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

> **Live Application:** [https://noahmclean.github.io/symmetry-workbench/](https://noahmclean.github.io/symmetry-workbench/)

An interactive point symmetry and periodic lattice explorer designed for undergraduate mineralogy students. Focuses on spatial clarity, geometric intuition, and testing symmetry operations without notation clutter.

## Features

- **Point Group Shapes (2D Crystals):** Explore rotational axes (1, 2, 3, 4, 6-fold) and mirror planes on crystallographic sections.
- **Wallpaper Patterns (Periodic Tilings):** Inspect glide-free plane groups and periodic unit cells.
- **Interactive Symmetry Toolbox:** Place and test rotation centers and reflection lines directly on the canvas.
- **Zero Build Step:** Built with vanilla HTML5, CSS3, ES6 modules, and Konva.js (via CDN). Runs directly in any modern web browser.

## Quick Start

Open `index.html` in any modern web browser, or serve locally with Python:

```bash
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000`.
